# Davies JR's Burger Menu

A responsive website showcase for Davies JR's BBQ Bacon Burger featuring nutrition information and order details.

## Features

- Clean, modern burger restaurant menu design
- Product showcase with high-quality imagery
- Nutrition information display
- Responsive layout with smooth hover effects
- Navigation menu
- Call-to-action "Order Now" button

## Project Structure

```
davies-burgers/
├── index.html          # Main HTML file
├── style.css           # Styling
└── README.md          # This file
```

## Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Styling and layout
- **Google Fonts** - Roboto and Oswald fonts

## External Resources

- Burger logo and product images from Codecademy
- Google Fonts for typography

## How to Use

1. Clone the repository or download the files
2. Open `index.html` in your web browser
3. Navigate through the menu and click "ORDER NOW" to explore

## Browser Compatibility

Works on all modern browsers including:

- Chrome
- Firefox
- Safari
- Edge
